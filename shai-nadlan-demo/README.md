# מערכת ניהול נדל”ן — דמו לשי עובדיה

מערכת לניהול תיק נדל”ן פרטי: נכסים, שוכרים וחוזי שכירות, עם דגש על התראות
לפני סיום חוזה ועל שימוש נוח מהנייד. עברית מלאה, RTL, ומצב כהה.

## מה יש במערכת

- **דשבורד** — שווי התיק, הכנסה חודשית ושנתית, תשואה ברוטו, תפוסה, והתראות על
  חוזים שמסתיימים (אדום עד 30 יום, כתום עד 90).
- **נכסים** — גריד עם תמונות, חיפוש וסינון לפי סטטוס, ועמוד נכס עם גלריה
  (העלאת תמונות מהמכשיר), פרטי הנכס, וכרטיס החוזה הפעיל עם פס התקדמות.
- **חוזים** — כל החוזים הפעילים מקובצים לפי דחיפות, עם חיוג ווטסאפ לשוכר בלחיצה.
- **הוספת נכס** — טופס עם ולידציה מוסברת לכל שדה.

## סטאק

Next.js 15 (App Router) · React 19 · Tailwind 4 · Supabase (Postgres + Auth +
Storage) · Vercel.

## הפעלה מקומית

```bash
npm install
cp .env.example .env.local   # ומלא את שני המשתנים
npm run dev
```

משתני סביבה:

| משתנה | תיאור |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | כתובת פרויקט ה-Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | מפתח anon (ציבורי, מוגן ב-RLS) |

## מסד הנתונים

`supabase/migrations/` מכיל את הסכימה המלאה, ו-`supabase/seed.sql` את דאטת הדמו
(21 נכסים, 18 שוכרים, 18 חוזים). כל טבלה מוגנת ב-RLS מהמיגרציה הראשונה: משתמש
רואה וכותב רק שורות שבבעלותו, ואנונימי לא רואה דבר.

```bash
npx supabase db push
psql "$DATABASE_URL" -f supabase/seed.sql
```
